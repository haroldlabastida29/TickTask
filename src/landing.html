The Problem We Solve

Students struggle to keep track of academic tasks and deadlines because busy schedules cause information to scatter across different sources such as group chats, class portals, notebooks, and paper notes.

Target Users

  • Working & Busy Students: Balancing jobs or heavy workloads.
  • Students Prone to Forgetting: Juggling multiple subjects simultaneously.

Core System Features & Architecture

Centralized Authentication

Secure accounts with isolated data persistence per user.

Hybrid Data Structures

Dynamic arrays combined with Hash Maps for instant lookups.

Linear Search & Filters

Quickly search keywords or filter records instantly.

Dual-Criteria Sorting

Orders tasks by deadline timestamps and priority weights.
